# Stateful Authorization for MCP Servers

This repository contains our code for the actual implementation of Stateful Authorization in MCP Servers/

## Setup & Installation
1. This project works best with UV. Install uv as `pip install uv`
2. Clone the repository and its submodules as: `git clone --recursive https://github.com/SirKanaad26/stateful-auth-for-mcp-servers.git`
3. Download the dependencies: `uv sync --locked`
4. Activate the virtual environment as: `source .venv/bin/activate`
